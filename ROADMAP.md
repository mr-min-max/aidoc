# Roadmap

## Now

Phase 5 is preparing the StaleDocs `0.3.0-beta.1` release candidate. Remaining work is release verification, publication, and the owner-only repository, npm, Marketplace, and metadata actions.

## Next

Candidates, not promises:

- README audit that reports when a mentioned symbol no longer exists.
- Documentation coverage badge.
- A breaking-change section in `staledocs changelog`.
- An MCP tool that returns the review report.

## Not planned

- New languages until users ask.
- VS Code extension.
- Website.
- Image generation.
- README beautification.
