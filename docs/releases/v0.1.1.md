# v0.1.1 Release Notes — Draft / Unreleased

## Problem

The v0.1.1 candidate addresses release-integrity gaps between the source tree
and the distributed npm package, GitHub Action, and MCP server. In particular,
the package needed its Handlebars prompts, automation failures needed to remain
visible to CI, and the MCP transport needed standards-compliant stdio framing.

## Change

- Ship the built-in Handlebars prompt templates in the npm tarball.
- Propagate GitHub Action generation, validation, and push failures.
- Add a deterministic AST-backed source/document co-change check.
- Use the official TypeScript MCP SDK over stdio.
- Derive CLI and MCP versions from installed package metadata.
- Require Node.js 22.12 or newer and gate release publication on Node 22 and
  Node 24 verification for the tagged SHA.
- Transfer one verified tarball into the privileged publish job instead of
  rebuilding or repacking it there.

## Verification

- The branch verification result is 25 passing test suites and 120 passing
  tests.
- Release checks cover the package tarball, GitHub Action, CLI check mode, and
  MCP client/server integration.
- The inspected artifact is `aidoc-gen-0.1.1.tgz`; it contains seven packaged
  Handlebars templates.
- Local verification ran on Node 24.12.0. Release CI requires successful Node
  22 and Node 24 matrix checks before publication.
- An online `npm audit --omit=dev` still requires maintainer consent for
  network access and is not claimed GREEN in this draft.

## Known limits

- The AST-backed co-change result shows whether selected source and document
  paths changed together; it is not semantic proof that documentation is
  correct.
- No `v0.1.1` tag, npm publication, GitHub Release, or public canonical
  repository exists yet.
- Provider-context secret detection and redaction is
  [in progress for v0.2.0-beta.1](../../ROADMAP.md#v020-beta1--trust-gate), not
  part of this release candidate.
- ProofGraph remains planned future work.
