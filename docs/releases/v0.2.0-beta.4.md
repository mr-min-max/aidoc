# Forthcoming v0.2.0-beta.4 integration

This note records the scoped source-checkout beta.4 candidate. The npm package
identity is `@mr-min-max/aidoc-gen`, while the installed executable remains
`aidoc`. This is not yet a claim that an npm artifact, GitHub Release, public
marketplace entry, or ChatGPT web local-STDIO integration exists.

beta.4 supersedes the unpublished beta.3 candidate. The beta.3 workflow
verified its artifact and generated provenance, but npm rejected its unscoped
name under the registry's package-similarity policy. No beta.3 package version
or GitHub Release was created, and its public tag is not moved or reused.

## Access boundaries

An eligible ChatGPT subscription authenticates the official local Codex host;
it does not become an OpenAI API key and AiDoc receives no ChatGPT OAuth token.
Claude Desktop and Claude Code authenticate their own host sessions; AiDoc
receives no Claude subscription token. Consumer subscriptions and API billing
are separate.

Direct provider mode supports exactly `openai`, `anthropic`, `deepseek`,
`qwen`, `openai-compatible`, and `ollama`. The remote credential variables are
`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `DEEPSEEK_API_KEY`,
`DASHSCOPE_API_KEY`, and `AIDOC_COMPAT_API_KEY`. Ollama is local and requires
an explicit installed model. Direct provider mode never silently falls back,
and Qwen custom calls are PAYG Model Studio API use rather than a subscription
bridge.

## Source-checkout verification

Until external publication proof succeeds, use the repository checkout:

```bash
npm install
npm run build
npm link
aidoc --version
```

Reverse the development link with:

```bash
npm unlink -g @mr-min-max/aidoc-gen
```

The release candidate must pass the full release gate, protected identity and
history preflight, exact scoped-name check, plugin smoke, hybrid demo, package
and MCP process smokes, and hosted Node 22/24 CI before an annotated
`v0.2.0-beta.4` tag can trigger publication.

## Security limits

MCP is pinned to one startup Git worktree and rejects external, traversal, Git
metadata, and symlink paths before project reads. Its configuration loader
accepts bounded declarative JSON/YAML/no-extension data, `package.json#aidoc`,
and the root `.env` allowlist; executable project configuration is rejected.
Direct CLI cosmiconfig and dotenv behavior remains unchanged.

These controls are not an operating-system sandbox. Privileged same-host
processes can race filesystem entries, hard links are indistinguishable from
ordinary files at this API level, provider network access remains governed by
the selected transport, and generated prose still requires human review.
