# StaleDocs 0.3.0-beta.1

Status: Published public beta

StaleDocs is a deterministic documentation drift check for pull requests. It reads supported source through ASTs, maps changed public symbols to documentation sections, and offers a focused assistant path for updates.

## What changed for users

- Broader TypeScript, JavaScript, and Python parser coverage.
- Before and after signatures in review and assistant context.
- Plan-aware `staledocs check` semantics.
- Review Action comments and labels.
- `.staledocsignore` suppressions.
- A rewritten README focused on pull request documentation drift.

This release includes a clean rename from AiDoc to StaleDocs. Environment variables now use `STALEDOCS_*`, the configuration namespace is `staledocs`, and the executable and package are `staledocs`; old names have no compatibility aliases. Renamed from aidoc. The tool checks documentation drift in pull requests; it is no longer only a generator. The old package `@mr-min-max/aidoc-gen` is deprecated and points to StaleDocs.
