# v0.2.0-beta.5

`0.2.0-beta.5` was published to npm and as a
[GitHub prerelease](https://github.com/mr-min-max/aidoc/releases/tag/v0.2.0-beta.5)
on 2026-08-14. The [successful release workflow](https://github.com/mr-min-max/aidoc/actions/runs/31825128025)
published through npm Trusted Publishing (OIDC) with no `NPM_TOKEN` or other
reusable npm credential in the workflow.

The release retains the beta.4 product behavior and strengthens the
verified-artifact pipeline: Node 22 and 24 verification, one packed tarball,
checksum validation, package and MCP smokes against those exact bytes,
publication on the explicit `beta` channel, npm provenance, and a
checksum-matching GitHub prerelease. The protected annotated tag points to the
exact reviewed `main` commit and uses the repository's approved GitHub noreply
identity.

Post-publication checks confirmed that `beta` points to `0.2.0-beta.5`, the
npm and GitHub tarballs match byte-for-byte, the attached checksum verifies,
the clean installed CLI reports `0.2.0-beta.5`, and npm exposes SLSA provenance
for `mr-min-max/aidoc` and `.github/workflows/release.yml`.

The post-publication account cleanup then set package publishing access to
disallow bypass tokens and deleted both temporary granular bootstrap tokens. A
safe authenticated follow-up audit reported zero active npm tokens and zero
temporary bypass tokens; no token identifier, value, or authenticator code was
recorded in the repository.

The supported install command remains:

```bash
npm install -g @mr-min-max/aidoc-gen@beta
```

Do not use a bare or `@latest` install for the prerelease channel. The
registry-managed `latest` tag is observed but is not moved or removed by this
release.
