# v0.2.0-beta.5

> **Release candidate:** beta.5 is not yet published. Until the OIDC-only
> release workflow succeeds, beta.4 remains the current public beta.

This candidate retires the temporary npm bootstrap path. Its GitHub Actions
publish job receives no reusable npm credential and can authenticate only
through npm Trusted Publishing for `mr-min-max/aidoc` and `release.yml`.

The release retains the beta.4 product behavior and verified-artifact
pipeline: Node 22 and 24 verification, one packed tarball, checksum validation,
package and MCP smokes against those exact bytes, publication on the explicit
`beta` channel, provenance, and a checksum-matching GitHub prerelease.

The supported install command remains:

```bash
npm install -g @mr-min-max/aidoc-gen@beta
```

Do not use a bare or `@latest` install for the prerelease channel. The
registry-managed `latest` tag is observed but is not moved or removed by this
release.
