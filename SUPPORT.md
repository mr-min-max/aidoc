# Support

StaleDocs is currently a public-beta candidate. Before asking for help, use Node.js
`>=22.12.0`, run `npm ci && npm run build`, and try the provider-free command:

```bash
node dist/cli/index.js plan
```

Use these channels:

- **Questions and usage help:** use the
  [Question / Support form](https://github.com/mr-min-max/staledocs/issues/new?template=question.yml).
- **Reproducible bugs:** [GitHub Issues](https://github.com/mr-min-max/staledocs/issues)
  using the bug form.
- **Feature proposals:** use the feature-request form.
- **Security vulnerabilities:**
  [private vulnerability reporting](https://github.com/mr-min-max/staledocs/security/advisories/new),
  never a public issue.

GitHub Discussions is not currently enabled. Use the question form instead of
guessing another contact channel.

Include the StaleDocs version or commit, Node version, operating system, the command
you ran, and a minimal repository fixture when possible. Remove credentials,
private source, absolute local paths, and personal data from logs before
sharing them.

Maintainers do not provide private consulting or guaranteed response times.
Focused reproductions and small pull requests are the fastest path to a useful
answer.
