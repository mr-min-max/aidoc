# Support

AiDoc is currently a public-beta candidate. Before asking for help, use Node.js
`>=22.12.0`, run `npm ci && npm run build`, and try the provider-free command:

```bash
node dist/cli/index.js plan
```

Use these channels:

- **Questions and usage help:** GitHub Discussions after the repository's
  public launch.
- **Reproducible bugs:** [GitHub Issues](https://github.com/mr-min-max/aidoc/issues)
  using the bug form.
- **Feature proposals:** the feature-request form or Discussions.
- **Security vulnerabilities:**
  [private vulnerability reporting](https://github.com/mr-min-max/aidoc/security/advisories/new),
  never a public issue.

Include the AiDoc version or commit, Node version, operating system, the command
you ran, and a minimal repository fixture when possible. Remove credentials,
private source, absolute local paths, and personal data from logs before
sharing them.

Maintainers do not provide private consulting or guaranteed response times.
Focused reproductions and small pull requests are the fastest path to a useful
answer.
